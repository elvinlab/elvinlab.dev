## T45 (#69) focus under the fixed header: measured (2026-10-05, no code changed)
Method: Playwright Chromium on production, 7 pages (`/`, `/me/`, `/contact/`, `/notes/`, a note, `/privacy/`, `/en/contact/`), 390 and 1280 px, 90 keyboard stops per page. - Proposed fix (NOT started, owner decides): one rule, `html { scroll-padding-top: <header height + a little> }` in `styles/global.css`, plus an e2e that Shift+Tabs through a page and asserts no focused element is covered by the header.
