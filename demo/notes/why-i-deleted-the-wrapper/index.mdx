The wrapper began as five lines. Six months later it had nine options and a README.

## How it grew

Every new caller asked for one small thing, and each ask was reasonable on its own. Nobody asked whether the layer still earned its place. I told myself <Fix wrong="it keeps the calls consistent" right="it hides what each call really does" />.

## The deletion

I removed it in one commit and let the type checker show me every caller.

```diff
- const user = await http.get('/user', { retries: 3, cache: 'short' });
+ const user = await fetch('/user').then((response) => response.json());
```

Two callers really needed retries. They now carry their own, and it is visible at the call site.

> Abstractions should be earned by repetition, not by optimism.
